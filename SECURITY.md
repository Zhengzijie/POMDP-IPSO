# Security Policy

## Supported version

Security and privacy fixes are applied to the latest repository version.

## Reporting a vulnerability or sensitive-data exposure

Do not open a public Issue for exposed credentials, personal information, restricted coordinates, unsafe flight behavior, or another vulnerability that could cause harm. Contact the corresponding author privately at `auzjzhang@scut.edu.cn` with the subject “POMDP-IPSO repository security report.” Include the affected file or commit, impact, reproduction details, and any recommended containment steps.

Do not exploit a vulnerability beyond what is necessary to demonstrate it. Do not download, redistribute, or retain restricted data. The maintainers will acknowledge a complete report when practicable, assess scope, remove or rotate exposed material, and publish a remediation note when disclosure is safe.

This research code is not certified for operational aviation, navigation, infrastructure inspection, or safety-critical deployment.
